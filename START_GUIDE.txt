================================================================================
                         HEALTHHERO - START GUIDE
                      Step-by-Step Setup Instructions
                         Offline ML Model Edition
================================================================================

  HealthHero now runs 100% offline using a locally trained Machine Learning
  model. No API key, no internet connection, no external services required.

================================================================================
STEP 1: PREREQUISITES
================================================================================

1.1  Check Python Version
     - Open Command Prompt or PowerShell
     - Run: python --version
     - You need Python 3.8 or higher
     - Download from: https://www.python.org/downloads/
     - IMPORTANT: During installation, check "Add Python to PATH"

1.2  Verify pip is installed
     - Run: pip --version
     - If not found: python -m ensurepip --upgrade

1.3  Verify git is installed (optional, for cloning)
     - Run: git --version
     - Download from: https://git-scm.com/downloads

================================================================================
STEP 2: GET THE PROJECT
================================================================================

  Option A — Clone from GitHub (recommended):

     git clone https://github.com/ishanuchaudhary/HealthHero.git
     cd HealthHero

  Option B — If you already have the folder:

     cd A:\HealthHero
     (or wherever your project is located)

  Verify you're in the correct directory:
     dir                         (Windows CMD)
     ls                          (PowerShell)

  You should see: app.py, llm.py, train_model.py, requirements.txt

================================================================================
STEP 3: SET UP VIRTUAL ENVIRONMENT (RECOMMENDED)
================================================================================

3.1  Create virtual environment:

     python -m venv venv

3.2  Activate it:

     Windows CMD:         venv\Scripts\activate
     Windows PowerShell:  venv\Scripts\Activate.ps1

     If PowerShell gives an execution policy error, run this first:
     Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

3.3  You should now see (venv) at the start of your terminal line.
     This means the virtual environment is active.

================================================================================
STEP 4: INSTALL DEPENDENCIES
================================================================================

4.1  Install all required packages:

     pip install -r requirements.txt

  This installs:
     - fastapi          Web framework
     - uvicorn          ASGI server
     - aiosqlite        Async SQLite database
     - python-jose      JWT authentication
     - python-multipart Form data handling
     - scikit-learn     Machine learning (RandomForest model)
     - pandas           Data processing for training
     - numpy            Numerical computation
     - joblib           Model saving and loading
     - httpx            HTTP client

4.2  Wait for all packages to install. You should see:
     "Successfully installed ..." at the end.

  TROUBLESHOOTING:
     - If you see errors, make sure your internet connection is active
     - Try: pip install --upgrade pip  then repeat step 4.1
     - If a package fails: pip install <package-name> individually

================================================================================
STEP 5: TRAIN THE ML MODEL  *** REQUIRED — DO THIS ONCE ***
================================================================================

  This step trains the disease prediction model on your machine.
  You only need to do this ONCE. After that, the model is saved locally.

5.1  Run the training script:

     python train_model.py

5.2  What happens during training:

     [1/5] Downloads the disease-symptom dataset (or uses built-in if offline)
     [2/5] Loads and preprocesses the data
     [3/5] Trains a RandomForest classifier (200 trees)
     [4/5] Evaluates accuracy on test data
     [5/5] Saves model artifacts to the model/ folder

5.3  Expected output:

     ==================================================
       HealthHero — Model Training
     ==================================================
     [1/5] Attempting dataset download ...
     [2/5] Loading & preprocessing data ...
           Training samples : 2400+
           Diseases (classes): 25
           Symptoms (features): 60
     [3/5] Training model ...
           Training RandomForest (200 trees) ...
           ✓ Training complete.
     [4/5] Evaluating model ...
           Test Accuracy : 95%+
           Macro F1-Score : 0.95+
     [5/5] Saving model artifacts ...
           ✓ Artifacts saved to ./model/
     ==================================================
       ✅ Done! Model accuracy: 95%+
     ==================================================

5.4  After training, verify the model/ folder was created:

     dir model\                  (Windows CMD)
     ls model/                   (PowerShell)

  You should see:
     model.pkl       Trained RandomForest classifier
     encoder.pkl     Label encoder for disease names
     symptoms.pkl    List of 60 symptom features
     diseases.pkl    List of all 25 disease names

  NOTE: If training fails due to no internet, it will automatically use the
  built-in dataset. The model will still train successfully.

================================================================================
STEP 6: START THE SERVER
================================================================================

6.1  Make sure you are in the HealthHero directory:

     cd A:\HealthHero

6.2  Make sure virtual environment is activated:
     You should see (venv) in your terminal.

6.3  Start the server:

     uvicorn app:app --reload

     OR:

     python -m uvicorn app:app --reload

6.4  Expected output:

     ✓ Local model loaded — 25 diseases, 60 symptoms
     INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
     INFO:     Started reloader process
     INFO:     Application startup complete.

  IMPORTANT: Make sure you see "✓ Local model loaded" — this confirms the
  trained model was found and is ready.

6.5  If you see "⚠ Model artifacts not found":
     - Stop the server (CTRL+C)
     - Run: python train_model.py
     - Then start the server again

================================================================================
STEP 7: ACCESS THE APPLICATION
================================================================================

7.1  Open your browser (Chrome, Firefox, Edge)

7.2  Go to:

     http://localhost:8000

     OR

     http://127.0.0.1:8000

7.3  You should see the HealthHero login/register page.

7.4  If the page doesn't load:
     - Check the terminal — make sure the server is still running
     - Refresh the page (F5)
     - Try a different browser
     - Check Windows Firewall isn't blocking port 8000

================================================================================
STEP 8: FIRST TIME SETUP
================================================================================

8.1  Register an Account:
     - Click the "Register" tab
     - Enter a username, email, and password
     - Click "Register"
     - You will be logged in automatically

8.2  Start Chatting:
     - Type your symptoms in the chat box
     - Examples:
         "I have fever, chills and joint pain"
         "I've been having headaches and nausea for 2 days"
         "I feel fatigue and have a skin rash"
     - HealthHero will predict possible conditions and give you guidance

8.3  Track Health Metrics:
     - Log daily water intake, steps, sleep, exercise, weight, heart rate

8.4  Set Reminders:
     - Create reminders for medications, water, meals, exercise

8.5  View Analytics:
     - Check your health trends and statistics in the dashboard

================================================================================
STEP 9: STOP THE SERVER
================================================================================

9.1  Go to the terminal where the server is running
9.2  Press CTRL + C
9.3  The server will stop gracefully

9.4  To restart, simply run:
     uvicorn app:app --reload

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "python is not recognized"
SOLUTION:
  - Python is not in your PATH
  - Reinstall Python and check "Add Python to PATH"
  - Or try: py --version  (Windows launcher)

PROBLEM: "ModuleNotFoundError: No module named 'sklearn'"
SOLUTION:
  - Run: pip install scikit-learn
  - Or reinstall all: pip install -r requirements.txt

PROBLEM: "ModuleNotFoundError: No module named 'joblib'"
SOLUTION:
  - Run: pip install joblib

PROBLEM: "⚠ Model artifacts not found in ./model/"
SOLUTION:
  - You haven't trained the model yet
  - Run: python train_model.py
  - Then restart the server

PROBLEM: "Port 8000 is already in use"
SOLUTION:
  - Use a different port:
    uvicorn app:app --reload --port 8001
  - Or find and kill the process:
    Windows CMD: netstat -ano | findstr :8000
    Then:        taskkill /PID <process_id> /F

PROBLEM: Training script fails with download error
SOLUTION:
  - The script will automatically fall back to the built-in dataset
  - Training will still complete successfully without internet

PROBLEM: "venv\Scripts\Activate.ps1 cannot be loaded"
SOLUTION:
  Run this in PowerShell:
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  Then activate again.

PROBLEM: pip install fails
SOLUTION:
  - Upgrade pip first:  python -m pip install --upgrade pip
  - Then retry:         pip install -r requirements.txt

PROBLEM: Browser shows "Connection refused"
SOLUTION:
  - Make sure the server is running (check terminal)
  - Try http://127.0.0.1:8000 instead of localhost
  - Check Windows Firewall settings

PROBLEM: Model gives wrong predictions
SOLUTION:
  - Use medical symptom keywords: fever, chills, nausea, fatigue, joint pain, etc.
  - Be specific — the more symptoms you mention, the better the prediction
  - Run: python llm.py  to test the model with sample inputs
